# ESG Document Assessment

ESG Document Assessment analyzes portfolio queries and uploaded PDF reports. The
React frontend is served by Nginx, which proxies API requests to the FastAPI
backend. The backend can use OpenAI-compatible models and a persistent Chroma
vector store.

## Run with Docker Compose

1. Copy `.env.example` to `.env`.
2. Replace the placeholders with local values. Generate an admin password hash
   with `python generate_admin_hash.py`; use a long, unique `SESSION_SECRET`.
3. Start the services:

   ```powershell
   docker compose up --build -d
   ```

The UI is available at `http://localhost:8081`. The backend is exposed only
inside the Compose network; Nginx proxies `/api/` and `/health` to it. No public
demo URL is configured by this repository. For HTTPS deployments, set
`COOKIE_SECURE=true` and terminate TLS at the public reverse proxy.

Compose stores application databases and Chroma data in the persistent
`esg_data` Docker volume mounted at `/data`. Do not commit environment files,
databases, vector-store data, or uploaded documents.

## Configuration

Required environment variables:

- `ESG_API_KEY`: API-key authentication for trusted clients.
- `SESSION_SECRET`: secret used to sign administrator sessions.
- `ADMIN_PASSWORD_HASH`: PBKDF2 hash generated by `generate_admin_hash.py`.

`OPENAI_API_KEY` is needed for model-backed SQL generation. Model names,
OpenAI-compatible base URL, Chroma collection, and the human-review threshold
can be customized with the variables shown in `compose.yaml`. Never put real
credentials in `.env.example`.

## API

- `GET /health` — health status.
- `POST /api/v1/analyze` and `POST /api/v1/analyze/stream` — portfolio analysis.
- `POST /api/v1/esg/document-assessment` — assess an uploaded PDF document.
- `POST /api/auth/login` and `/api/auth/logout` — administrator session.

The API is served through the frontend origin in the default Compose setup.
Document assessment accepts PDFs up to 20 MB. Results are evidence summaries,
not compliance verdicts; scanned documents require OCR before assessment.

## Development and tests

Backend tests:

```powershell
python -m pytest
```

Frontend type-check and production build:

```powershell
Set-Location frontend
npm ci
npm run build
```

Before deploying, validate the Compose configuration with
`docker compose config --quiet`.
